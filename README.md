# 中文文本阅读难度分级（HSK Text Difficulty）

**在线试用：<https://luseptem.github.io/hsk-Chinese-text-difficulty/>**

打开网页 → 粘贴一段中文 → 点「开始分析」→ 立刻得到难度分数与 1~7 级评级。

---

## 一、依据

本工具实现的是程勇、董军、晋淑华《基于新标准的汉语二语文本阅读难度分级体系构建与应用》
（《世界汉语教学》2023 年第 1 期）提出的难度公式：

```
难度 = (1/3) × Σ(n=1→7) n × [ r字(n) + r词(n) + r语法(n) ]
```

其中：

- `r字(n)` = 第 n 级**字种数** ÷ 总字种数
- `r词(n)` = 第 n 级**词种数** ÷ 总词种数
- `r语法(n)` = 第 n 级**语法点类型数** ÷ 总语法点类型数

三个维度等权平均，n 取《国际中文教育中文水平等级标准》(GF 0025-2021) 的 1~7 级
（第 7 级代表「七—九级」）。

## 二、分级阈值

采用论文表 8 的划分：

| 难度分 | 评级 |
| --- | --- |
| [1, 1.4) | 一级 |
| [1.4, 1.75) | 二级 |
| [1.75, 2) | 三级 |
| [2, 2.3) | 四级 |
| [2.3, 2.55) | 五级 |
| [2.55, 2.7) | 六级 |
| [2.7, 7] | 七—九级 |

页面同时给出 HSK 3.0 等级与 CEFR 的参考对应，便于对外说明。

## 三、数据来源

全部取自《国际中文教育中文水平等级标准》(GF 0025-2021) 官方量表，数量与原标准一致：

| 量表 | 数量 | 各级分布 |
| --- | --- | --- |
| 分级汉字表 | 3000 | 300 / 300 / 300 / 300 / 300 / 300 / 1200 |
| 分级词汇表 | 11092 | 500 / 772 / 973 / 1000 / 1071 / 1140 / 5636 |
| 语法等级大纲 | 572 条 | — |

语法维度由大纲自动编译成规则库，本工具覆盖其中 523 条（约 91%）。

## 四、结果页包含什么

- 难度分数、评级色标、在分级标尺上的位置
- 汉字 / 词汇 / 语法三个维度各自的 `Σn×r(n)`
- 三个维度在 1~7 级的分布柱状图
- 五级及以上高级别词语清单（含级别与出现次数）
- 识别到的语法点及命中证据
- 表外字 / 表外词清单
- 分析过程的 6 个阶段与每步耗时

## 五、三点已知取舍

1. **表外词默认不计入难度**（界面可切换）。官方词表只收「中国」，不收「美国」「英国」；
   若把分词产生的表外词一律算作七级，分数会明显虚高。
2. **「把」字句 1-5、被动句 1-5 这类递进变体**用正则难以区分，
   统一按该句型的引入级别计一次，避免一个「被」字同时点亮 3~7 级。
3. **语法规则库覆盖约 91%**；识别不了的条目（如「句群」）宁可不覆盖也不硬判。

如需用于正式研究，建议先用你自己的教材语料跑一遍复核校准。
